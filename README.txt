# Physio Booking Backend (PoC)

Spring Boot backend for appointment booking with physiotherapists.

## Tech stack
- Java 21
- Spring Boot 3.1.4
- Spring cloud 2022.0.4
- Spring Security
- Spring Data JPA
- PostgreSQL
- Resilience4j
POST → uses manual reactive control (operator)
GET → uses declarative resilience (annotation)

## Status
PoC / self-learning project
